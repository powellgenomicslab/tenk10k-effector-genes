# 3-comparison: Agreement between gene-implication methods

Compares the cell-type-specific MR results against the other methods applied to
the same traits, quantifying where they agree and where they do not.

| Script | Purpose |
|---|---|
| `coloc_mr_overlap.R` | Overlap between MR and colocalisation evidence, by trait category |
| `mr_magma_eqtlgen.R` | MR against MAGMA gene-level association and against eQTLGen bulk MR, including example loci |

Both source `scripts/0-preprocess/preprocess_results.R`, which supplies the
harmonised evidence table and the significance thresholds (mSMR `lfdr < 0.05`
per phenotype; coloc `PP.H4 >= 0.8`).

`mr_magma_eqtlgen.R` additionally reads per-locus GWAS and LD dumps under
`results/gwas_locus/` for its example panels. Those are donor-derived and not
part of the public data release, so the locus panels cannot be regenerated by a
third party; the summary comparisons can.
